Featured Games

Bluff Game

My MSc dissertation project: a turn-based card bluffing game in Unreal Engine 5. Three AI opponents — Tactical, Manipulator and Adaptive — extend a shared base class and resolve their moves through one common decision structure, so each reads a bluff and commits to it differently.

Supporting systems handle turn order, hand management and running player stats, with a full UI flow covering declarations, an action bar, live stats, a pause menu and a win screen. Because the archetypes share one decision pipeline, their differences come from tuning rather than duplicated logic — adding a fourth personality means adding a subclass, not rewriting the turn loop.

3D Chase Game

MSc coursework for Advanced Game Technologies, written in C++ on Newcastle's nclgl framework and rendered with OpenGL. The player rolls a physics-driven ball through a maze arena while AI hunters close in — breaking off to grab a power-up when that suits them better than a direct chase.

Each hunter runs a behaviour tree whose root is a selector: it first attempts a sequence — find the nearest power-up, then path to it — and falls back to chasing the player directly when no pickup is worth taking. Movement is A* across a navigation grid, re-pathed on a timer so hunters react to where the player is now rather than following a route computed at spawn. Maze walls use oriented bounding boxes for collision, three pickups respawn on their own timers, and the game runs through a menu, playing and game-over state machine with a survival clock.

Volcano Eruption

MSc coursework for Advanced Graphics for Games, written in C++ on Newcastle's nclgl framework and rendered with OpenGL. A volcanic landscape drawn across several render passes, with the eruption itself running on a 1,200-particle system of lava, vapour and smoke over shadow-mapped terrain.

The frame builds up in passes: a depth-only shadow pass from the light's viewpoint into a 2048² map, a skybox, heightmap terrain, then a scene graph traversed against the view frustum so only what is on screen gets submitted. The terrain shader blends two textures by altitude, layers three scales of noise so the surface never tiles visibly, applies tangent-space bump mapping and samples the shadow map for contact shadows. Each particle type carries its own gravity, lifetime and blend mode, so molten rock arcs and falls while smoke climbs and thins. Day and night lighting, eruption intensity and an animated ground-cracking effect are switchable at runtime.

Push/Pull Parkour

A six-person MSc team project: a push/pull parkour game written in C++ and built for both PC and PS5 through a Jenkins CI pipeline. I owned most of the UI, the skeletal animation pipeline and the input layer, plus a share of the gameplay.

My largest pieces were the animation pipeline — GLTF and Assimp model import feeding an ozz-animation runtime, with GPU skinning in the scene shaders — and the front-end state machine covering the main menu, level select, controls, pause, end-of-level and both the local and networked game states. I also wrote the input layer, mapping keyboard and mouse alongside PS5 DualSense bindings so the same levels play on either platform, and worked on player movement and multiplayer bug fixing. Levels run from a tutorial through the push and pull mechanics to a vertical city.

C++ OpenGL PS5 Skeletal Animation Team Project

Sprite Flight

A 2D score-attack survival game in Unity. The player steers a craft that rotates to face its heading through a field of obstacles, each spawned at a random scale and fired off with a random impulse, so no two runs ever play out the same way.

Score climbs with survival time, and a collision triggers a particle burst and an instant restart from the same screen. Built against Unity's Input System and UI Toolkit rather than the legacy input manager and uGUI: the HUD is a UIDocument queried at runtime, and movement is applied through Rigidbody2D inside FixedUpdate so the handling stays framerate independent.
